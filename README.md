# Window Mute

**Instantly mute or unmute all tabs within the current browser window with a single click.**

---

## Features
- **Single-Click Toggle**: Mute or unmute all tabs in your current browser window instantly by clicking the toolbar icon.
- **Auto-Mute New Tabs**: New tabs automatically inherit the current window's mute state.
- **Per-Window Mute State**: Mute states are isolated to each individual browser window. Muting one window will not affect audio playing in other open windows.
- **Persistent Window State (Firefox Only)**: Preserve window mute state across browser restarts.

---

## Planned Features
Here is what's coming next:

- **Keyboard Shortcuts**: Support for configurable keyboard shortcuts.
- **Persistent Window State (Chromium)**: Persistent mute states across browser restarts for Chromium browsers.
- **Domain-Based Auto-Mute Rules**: Whitelist or blacklist specific domain names to automatically adjust mute behavior on navigation.
- **Tab Group Muting**: Toggle mute states for entire browser tab groups in one click.
